4.2 Data comparison and statistics

RNA reads (insertions) will be matched against a pre-constructed reference genome database using STAR comparison software. Based on the STAR comparison results, combined with the information in the reference dataset (gtf/gff file), reads coverage information of each region of the genome was analyzed to obtain the ratio information of exons, introns and intergene regions, which could be used as a reference index for data quality control. 4.4 Data quality control and filtering

Commonly used QC filtration conditions mainly include:

(1) The number of genes identified per cell: a) Low quality cells or empty droplets usually identify very few genes; b) Twin or polycellular droplets may exhibit an unusually high number of genes.

(2) The number of molecules identified per cell (similar to 1);

(3) The ratio to the mitochondrial genome;

Cell Ranger uses the EmptyDrops algorithm to automatically distinguish real cells from empty droplets. On this basis, commonly used cell filtration parameters for downstream analysis are:

(1) Filter out cells with a gene number less than 200 or greater than the maximum gene number *90%;

(2) Cells with more than 5% of mitochondrial reads were filtered out (cell types with high energy requirements required special treatment, such as tumor tissue and cardiomyocytes, and the general threshold was set to more than 20%);

4.5 High variable feature screening

Calculating subsets that exhibit highly differentiated features between cells in the dataset (i.e., they are highly expressed in some cells and low expressed in others), focusing on these genes in downstream analysis helps highlight biological signals in single-cell datasets. By default, the 2,000 genes with the highest degree of variation are selected. These genes will be used for downstream analysis, such as PCA.

4.6 Cell clustering

In factor analysis technology, variables are grouped according to their correlation, that is, all variables in a specific group have a high correlation with each other, but often have a low correlation with variables in other groups. Then, the most significant principal component is selected according to the degree of enrichment and P-value. According to tSNE or UMAP (https://www.nature.com/articles/nbt.4314) algorithm of nonlinear dimension reduction analysis, the cells together into classes. The UMAP algorithm is adopted by default for the following reasons: UMAP is more suitable for processing large data sets and complex dimensional information. Combines the power of visualization with the ability to reduce data dimensions; In addition to preserving the local structure, it also preserves the global structure of the data. (The Ultimate Guide to 12 Dimensionality Reduction Techniques (with Python codes))

It is feature-rich and widely adopted in the single-cell sequencing community.
SingleRv2.2.0SingleR compares each cluster from cell clustering results against reference databases, scoring clusters based on the similarity of their gene expression profiles to known cell populations. The resulting score matrix enables automated cell type annotation for each cluster.
CellChatv2.0.0CellChat quantitatively infers and analyzes intercellular communication networks from single-cell data. It uses network analysis and pattern recognition methods to predict major signaling inputs and outputs of cells, and how these cells and signals coordinate biological functions.
