1 Format of Sequencing Data

10X single-cell sequencing data are stored in FASTQ format, which is the standard output format for Illumina sequencing platform. See attached Figure 3 for examples of data. This file consists of four action units: the first line begins with '@', followed by the sequence description; The second line is the sequence; The third line begins with a '+', which may or may not be followed by the sequence description; The fourth line is the base quality value of the second line sequence, and the two lines are correspond one by one. An example is shown as the following:


@A00228:279:HFWFVDMXX:1:1101:8486:1000 2:N:0:NCATTACT
NACAAAGTCCCCCCCATAATACAGGGGGAGCCACTTGGGCAGGAGGCAGGGAGGGGTCCATTCCCCCTGGTGGGGCTGGTGGGGAGCTG
+
#FFFFFFFFFFFFFFF:FFFFFFF:FFFFFFFFFFFFFFFFFFFFFFFFFF:FFFFFFFFFFFFFFFF:FFFFFFFFFFFFFFFFFFFF
