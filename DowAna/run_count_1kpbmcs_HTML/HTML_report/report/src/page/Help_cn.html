1 测序下机数据格式

10X单细胞测序下机数据以FASTQ格式存储，是Illumina测序平台的标准输出格式。数据示例参见附图3。该文件以4行为单位，代表1条read的信息：第一行有'@'开头，后面跟随序列的描述信息；第二行是序列；第三行由'+'开始，后面也可以跟随序列的描述信息，也可不跟；第四行为第二行序列的碱基质量值，两行一一对应，示例如下：
