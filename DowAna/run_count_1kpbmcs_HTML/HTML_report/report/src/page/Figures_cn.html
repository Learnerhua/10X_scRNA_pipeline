X轴表示平均表达量,Y轴表示标准化方差,右图在左图基础上标注了表达量变异程度top 10的marker基因。
图5  Top15 PC的降维热图。   
每列表示一个细胞， 每行表示一个基因； 黄色表示高表达， 紫色表示低表达。
图6  Top15 PC的elbow plot图。   
X轴为PC序号， Y轴为标准差。
图7  DoubletFinder 识别的双胞（核）以及非双胞。   
每个点表示一个细胞。不同颜色表示细胞类型，红色表示细胞为双胞（核），青色表示细胞为非双胞。
图8  DecontX 识别污染细胞。   
每个点表示一个细胞。不同颜色表示细胞类型，红色表示细胞被污染可能性较高，青色表示细胞被污染的可能性较低。
图9  细胞聚类结果。   
X轴表示的是UMAP第一成分， Y轴表示的是UMAP第二成分。 数字和颜色代表cluster编号。
图10  Marker基因聚类热图。   
横坐标为不同的细胞类群；纵坐标为Marker基因；黄色代表高表达，紫色代表低表达。
图11  Marker基因气泡热图。   
横坐标为Marker基因，纵坐标为不同的细胞类群；颜色从浅到深，颜色越深表示基因平均表达量越高；圆形越大表示表达该基因的细胞数目越多。
图12  Marker基因小提琴图。   
纵坐标为不同细胞类群，横坐标为Marker 基因表达量，数字越高表示基因的表达量越高。
